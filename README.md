# Pingramm

Pinterest-style image sharing platform built with Django REST Framework and React.

## 🛠️ Tech Stack

### Backend
- Python
- Django
- Django REST Framework
- JWT Authentication
- SQLite

### Frontend
- React
- Vite
- Axios
- CSS

## ✨ Features

- User authentication
- Image upload
- Image feed
- Like system
- Save images
- Comments
- Follow users
- User profiles
- Search

## 🚀 Run Locally

### Backend

```bash
python -m venv venv
venv\Scripts\activate
